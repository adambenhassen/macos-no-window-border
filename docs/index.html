NoBorder

The look of fullscreen, without fullscreen mode.

Maximized windows go edge to edge: no outline, no rounded corners, no titlebar rim. The menu bar and Dock stay put, the window stays on your current Space, and nothing slides away.

Download View on GitHub

What it changes

→

Outline and shadow

The 1px gray line WindowServer draws around every window, and the drop shadow it belongs to.

→

Rounded corners

Corners go square, so a maximized window meets the screen edge with no wallpaper showing through.

→

Titlebar rim

The light highlight along the titlebar's top edge (and the line under the titlebar).

Only maximized windows

A window counts as maximized when it fills its screen's usable area: below the menu bar, beside the Dock. Every other window keeps the normal macOS look. A window gets its normal look back when you un-maximize it, turn NoBorder off, or quit it, unless its app stays busy. A busy app's windows can stay changed if the app is busy when NoBorder quits.

Requirements

  • System Integrity Protection disabled. NoBorder attaches a debugger to Dock and to your apps, which SIP forbids. Disabling SIP weakens macOS security; read Apple's guide before you do it.
  • Xcode installed. NoBorder uses the LLDB that ships with it.
  • macOS 14 or later. Tested on macOS 15.

Install

Download

  1. Download NoBorder.zip and unzip it.
  2. Move NoBorder.app to Applications and open it.
  3. It isn't notarized, so macOS blocks the first launch. Open System Settings › Privacy & Security and click Open Anyway.

Build from source

git clone https://github.com/adambenhassen/macos-no-window-border
cd macos-no-window-border
make install
open /Applications/NoBorder.app

The menu bar icon shows the status and has Enabled, Launch at Login and Quit.

Costs and limits

  • An app freezes for about a second each time one of its windows becomes or stops being maximized.
  • NoBorder leaves an app alone for its first 30 seconds after launch.
  • Only AppKit windows change corners. That includes Chromium and Electron apps.
  • NoBorder uses private macOS APIs, so a macOS update can break it.

How it works

A small daemon keeps an LLDB session attached to Dock and calls WindowServer from inside it to set each maximized window's no-shadow tag, which removes the outline. For corners and the rim, it briefly attaches to the window's app and queues two AppKit calls on the app's main run loop. Details are in the README.
